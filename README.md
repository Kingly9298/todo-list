#The To-Do
##A Place to Get Organized

A simple site where you can write down tasks, the time it'll take, and how important they are/their priority. As you continue to finish the progress bar gets filled up as well! Loads of other features are also present.

With this project, I was able to learn a lot of Python, through YouTube tutorials and I feel proud of my progress about learning about GUI's and Tkinter and it's features. 

This project was made with Python on VS Code, to run it you can simply put the code into VS Code and try it out

I had to fix lots of stuff throughout the project, I constantly forgot about "global"-ing variables in functions or like being able to use them and also made lots of mistakes with typos in ym variable names causing confusion at first until I realized how bad my typing skills are. 

My project was made to help me learn Tkinter and GUI's in Python and to have a site to stay organized with my tasks afterschool.
